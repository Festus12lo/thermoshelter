PHASE 1 — SOURCE REGISTRY
--------------------------------------------------

Read source_registry.csv.

For EVERY source:

1. Identify source name.
2. Identify source type.
3. Identify URL.
4. Identify cited chapter/table/section/page if available.
5. Verify whether the URL is reachable.
6. Verify that the source is actually authoritative for the claimed information.
7. Record:
   - VERIFIED
   - PARTIALLY VERIFIED
   - NOT VERIFIED
   - INACCESSIBLE

Do not assume a URL is valid merely because it exists in the CSV.

--------------------------------------------------
PHASE 2 — MATERIAL PROPERTY TRACEABILITY
--------------------------------------------------

Read materials_v2.csv and material_sources.csv.

For EVERY material property that claims an external source:

Check:

- thermal conductivity
- density
- specific heat
- emissivity
- absorptivity
- reflectivity
- moisture-related values
- hygrothermal properties
- any other sourced property

For each important property determine:

1. Source cited?
2. Source accessible?
3. Property actually present in source?
4. Units match?
5. Value matches?
6. Source condition matches?
7. Is the value measured, tabulated, assumed, or calculated?
8. Is the confidence level justified?

Do NOT silently correct values.

If a source does not clearly support a value, mark:

NOT VERIFIED — INSUFFICIENT SOURCE EVIDENCE

--------------------------------------------------
PHASE 3 — CALCULATED VALUES
--------------------------------------------------

Identify all values marked CALCULATED.

Verify calculations independently.

Examples:

R = thickness / thermal_conductivity

U = 1 / R_total

Check:

- units
- arithmetic
- layer ordering
- inclusion/exclusion of surface resistances
- rounding

Report any discrepancy.
