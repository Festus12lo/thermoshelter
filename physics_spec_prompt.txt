==================================================
1. MODEL OBJECTIVE
==================================================

Given:

- hourly outdoor weather
- shelter geometry
- shelter material configuration
- openings
- orientation
- ventilation level
- occupancy

calculate an approximate hourly indoor air temperature.

The model must be transparent, deterministic, documented, and testable.

==================================================
3. CORE PHYSICS
==================================================

A. CONDUCTION

For a homogeneous layer:

R = L / (k*A)

Q_cond = (T_out - T_in) / R

For multiple layers:

R_total = sum(L_i / (k_i*A))

Calculate separate conductive heat-transfer paths for:

- walls
- roof
- floor

Account for window and door openings when calculating net opaque wall area.

Do not double-count areas.

--------------------------------------------------

B. THERMAL MASS

For each thermal mass component:

C = rho * V * cp

where:

rho = density
V = material volume
cp = specific heat

Calculate an effective shelter thermal capacitance.

Use this capacitance to make indoor temperature respond dynamically to hourly weather instead of assuming instantaneous equilibrium.

--------------------------------------------------

C. THERMAL DIFFUSIVITY

Where useful:

alpha = k / (rho * cp)

Use this primarily for diagnostics/documentation in V1.

Do not implement a complicated multidimensional finite-difference wall model.

--------------------------------------------------

D. SOLAR GAIN

Use the existing shortwave_radiation weather variable.

Basic absorbed solar heat:

Q_solar = solar_absorptivity * I * A_exposed

where:

I = incident shortwave radiation

For V1, use a documented simplified orientation/shading treatment.

Do NOT pretend that the current weather dataset provides surface-specific solar irradiance.

Clearly document this as a V1 approximation.

--------------------------------------------------

E. VENTILATION / INFILTRATION

Use the existing ventilation_level field.

For V1, map qualitative ventilation levels to documented assumed ACH values.

Use:

Vdot = ACH * V_room / 3600

mdot = rho_air * Vdot

Q_vent = mdot * cp_air * (T_out - T_in)

Document the assumed ACH values and their limitations.

Do not modify shelter_schema.json just to introduce ACH in V1.

--------------------------------------------------

F. INTERNAL HEAT GAINS

Use occupant_count.

Model:

Q_people = occupant_count * sensible_heat_per_person

Use a clearly documented V1 assumption for sensible heat per occupant.

Do not pretend this represents detailed metabolic activity.

--------------------------------------------------

G. SURFACE RADIATION

Use emissivity where appropriate.

For V1, use a simplified long-wave radiation treatment if required by the model.

If a simplified external radiation assumption is used, document it explicitly.

Do not create a fake precision model.

==================================================
4. HOURLY ENERGY BALANCE
==================================================

Use an hourly timestep:

dt = 3600 seconds

At each timestep calculate:

Q_net =
Q_conduction
+ Q_solar
+ Q_people
- Q_vent
- Q_other_losses

Then update indoor temperature using the effective thermal capacitance:

T_in_next =
T_in +
(Q_net * dt / C_effective)

Use consistent SI units throughout.

Clearly document the sign convention.

11. PHYSICS SANITY CHECKS
==================================================

The implementation must include sanity checks.

Examples:

- Increasing wall thickness should generally reduce conductive heat transfer.
- Increasing thermal conductivity should generally increase conductive heat transfer.
- Increasing solar absorptivity should generally increase solar gain.
- Increasing ventilation should generally increase outdoor-air heat exchange.
- Increasing thermal mass should reduce rapid indoor temperature swings.

These are directional checks, not universal claims under every interacting condition.
